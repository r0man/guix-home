** Installation

Configure the Guix channels.

#+begin_src shell
  mkdir -p ~/.config/guix/
  rm -f ~/.config/guix/channels.scm
  ln -s "$(pwd)/modules/r0man/guix/channels.scm" ~/.config/guix/channels.scm
#+end_src

** Usage

Pull latest channel updates.

#+begin_src shell
  guix pull --unsafe-channel-evaluation
#+end_src
*** M1

Reconfigure the system.

#+begin_src shell
  sudo ~/.config/guix/current/bin/guix system -L modules reconfigure modules/r0man/guix/system/m1.scm
#+end_src

Reconfigure the home environment.

#+begin_src shell
  guix home -L modules reconfigure modules/r0man/guix/home/environments/m1.scm
#+end_src

Build the system with time machine.

#+begin_src shell
  guix time-machine -C modules/r0man/guix/channels.scm --unsafe-channel-evaluation -- system build -L modules modules/r0man/guix/system/m1.scm
#+end_src
